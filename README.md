
  # Intern Recruitment App

  This is a code bundle for Intern Recruitment App. The original project is available at https://www.figma.com/design/zTMJzOY89Y3tTMJltdIfgc/Intern-Recruitment-App.

  ## Running the code

  Run `npm i` to install the dependencies.

  Start the mock API server with `npm run server` (port 4000 by default).

  Run `npm run dev` to start the development server.
